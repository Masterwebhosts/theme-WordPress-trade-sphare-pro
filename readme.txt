== Description ==

Trade Sphare Pro is a flexible, modern and responsive WordPress theme designed for blogs, content websites, personal websites, business websites and digital platforms.

The theme provides a clean foundation with customizable colors, homepage settings, responsive layouts, navigation menus, widget areas and standard WordPress theme features.

It works with the WordPress block editor and supports custom logos, featured images, navigation menus, wide content alignment, responsive embeds, HTML5 markup and threaded comments.

The theme is translation-ready and supports both left-to-right (LTR) and right-to-left (RTL) languages.

Trade Sphare Pro is designed to provide a flexible foundation that can be adapted to different types of WordPress websites.

== Installation ==

1. Download the Trade Sphare Pro theme ZIP file.
2. Log in to your WordPress administration area.
3. Go to Appearance > Themes > Add New.
4. Select Upload Theme.
5. Upload the Trade Sphare Pro ZIP file.
6. Install the theme.
7. Activate the theme.

== Recommended Setup ==

After activating Trade Sphare Pro:

1. Go to Appearance > Customize and configure the available theme settings.
2. Add your site logo from the Site Identity settings.
3. Create a primary navigation menu under Appearance > Menus.
4. Assign the menu to the Primary Navigation location.
5. Create footer menus if required.
6. Assign footer menus to the available footer locations.
7. Go to Appearance > Widgets and configure the available sidebar widgets.
8. Create posts and pages using the WordPress block editor.
9. Set your preferred homepage configuration under Settings > Reading.
